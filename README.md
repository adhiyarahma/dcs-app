# 📂 DCS App — Document Control System

Platform manajemen dokumen terkontrol tingkat perusahaan yang dirancang untuk efisiensi, kepatuhan (compliance), dan keamanan data. Sistem ini mengelola siklus hidup dokumen mulai dari draf, revisi, hingga status *obsolete*.

---

## ✨ Fitur Utama

*   **🛡️ Role-Based Access Control (RBAC):** Proteksi halaman ketat antara Administrator dan User biasa menggunakan NextAuth.js.
*   **📄 Document Life-Cycle Management:** Pelacakan nomor dokumen (SOP/WI/Form) dengan status real-time (Active, Revision, Obsolete).
*   **🎨 Modern Enterprise UI:** Antarmuka bersih menggunakan *Plus Jakarta Sans* dan tema *Deep Navy* yang elegan.
*   **⚡ Server-Side Rendering:** Performa cepat dengan Next.js App Router dan validasi data sisi server.

---

## 🛠️ Stack Teknologi

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Authentication:** NextAuth.js
- **Database:** PostgreSQL
- **Icons:** HeroIcons
- **Typography:** Plus Jakarta Sans & DM Mono
